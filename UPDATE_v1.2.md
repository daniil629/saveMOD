# Обновление 1.2 — фото-приветствие

Что изменилось:

- `/start` теперь отправляет фиолетовый баннер «ДОБРО ПОЖАЛОВАТЬ»;
- под баннером находится короткое описание функций;
- оставлены только две кнопки: «📖 Как пользоваться?» и «💬 Поддержка»;
- инструкция открывается внутри чата с ботом;
- поддержка ведёт на https://t.me/ovexiu;
- Mini App, «Создать бота», «Мои боты» и другие лишние кнопки отсутствуют.

## Установка поверх предыдущей версии

1. Остановите бота клавишами `Ctrl+C`.
2. Распакуйте архив `message_keeper_bot_v1.2.zip` в `C:\Users\user\Desktop` и подтвердите замену файлов.
3. Не удаляйте `.env` и `data`: токен, база и медиа сохранятся.
4. Запустите:

```powershell
Set-Location "C:\Users\user\Desktop\message_keeper_bot"
python -m app.main
```

5. Откройте диалог с @SaveeBooot_bot и отправьте `/start`.

Новые зависимости не требуются. Баннер уже включён в архив по пути `app/assets/welcome.png`.
