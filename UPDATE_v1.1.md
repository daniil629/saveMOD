# Обновление 1.1 — новое оформление

Изменения:

- компактные карточки удаления и редактирования по присланным примерам;
- «Было / Стало» без лишних метаданных;
- контекст «В ответ на: …» для новых сохранённых сообщений;
- медиа отправляется над карточкой уведомления;
- отдельное оформление самоуничтожающихся фото и видео;
- внизу автоматически указывается username вашего бота;
- существующая база SQLite автоматически обновляется без удаления истории.

## Как установить на Windows

1. Остановите работающего бота клавишами `Ctrl+C` в PowerShell.
2. Распакуйте новый архив в `C:\Users\user\Desktop` и подтвердите замену файлов папки `message_keeper_bot`.
3. Не удаляйте свои файлы `.env` и папку `data`: в архиве их нет, при замене они сохранятся.
4. Запустите из корня проекта:

```powershell
Set-Location "C:\Users\user\Desktop\message_keeper_bot"
python -m app.main
```

Новые зависимости устанавливать не нужно. Контекст «В ответ на» появится у сообщений, полученных после обновления; у ранее сохранённых записей этой информации не было.
